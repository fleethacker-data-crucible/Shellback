FOUNDATIONS / TRUST

Evidence stays in its lane.

Separating signals is a core product requirement. There is no opaque universal skill score and no automatic employment decision.

01 · Résumé claim

A keyword match proposes a skill for review. It cannot establish ability or currency.

02 · Confidence

Self-report to a task-specific prompt; not a verified measure of competency.

03 · Execution mode

Independent, guided, and approved AI-assisted accomplishment are separate, not collapsed.

04 · Recent activity

Only voluntary declarations. Missing or old records mean unknown, not deficient.

05 · Credentials

Self-entered inventory; authoritative verification requires approved external systems.

06 · Employee agency

Correct, withdraw sharing, export, or delete the local profile. No passive telemetry.

Data boundaries

This browser stores only local application data. Nothing is sent to a server by this MVP.

Local storage is accessible to anyone using the same browser profile. For real personnel data, deploy an approved backend with identity, access control, encryption, audit logging, records retention, privacy and labor review, and an ATO where required. Do not place actual personnel data into this offline prototype on a shared workstation.
